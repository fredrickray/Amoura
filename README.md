# Amoura

Luxury lifestyle storefront for **perfumes**, **customized magazines**, and **lashes** — inspired by the [Essential Framer template](https://essential.framer.media/#hero).

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Route | Purpose |
| --- | --- |
| `/` | Home — hero, trust bar, featured catalogues, methods, blog, FAQ |
| `/store` | Full product line-up across all three catalogues |
| `/product/[slug]` | Product detail with gallery, accordions, similar items |
| `/blog` | Editorial reads |
| `/methods` | Craft pillars for scent, print, and lashes |
| `/support` | Contact + FAQ |
